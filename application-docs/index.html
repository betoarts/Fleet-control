Fleet Control 🚗📊

Fleet Control é uma solução abrangente de gerenciamento de frota desenvolvida para a Controle de Frota. Combina uma aplicação web moderna em React com capacidades Nativas Mobile via Capacitor, permitindo o gerenciamento eficiente de viagens, disponibilidade de veículos e desempenho dos motoristas.


Destaques: Análise com IA, Rastreamento em Tempo Real, Dashboard Administrativo e Segurança Biométrica.

Mobile & Web (PWA)

Esta aplicação foi construída como um Progressive Web App (PWA) e empacotada com Capacitor para uma experiência nativa em Android/iOS.

Funcionalidades Nativas Mobile

  • Segurança Desbloqueio Biométrico: Acesso seguro usando Impressão Digital/FaceID.
  • GPS Geolocalização em Segundo Plano: Rastreia coordenadas da rota com precisão.
  • UX Feedback Háptico: Resposta tátil para ações.
  • Estado Auto-Lock: Bloqueio automático ao minimizar.

Funcionalidades Web

  • Design Responsivo (Desktop, Tablet, Mobile)
  • Capacidade Offline (Service Workers)
  • Instalável via Navegador

Módulos Funcionais

1. App do Usuário (Motorista)

  • Registro de Viagem: Fluxo "Iniciar/Parar" com validação de KM.
  • Itinerário Inteligente: A IA analisa e categoriza viagens.
  • Histórico: Registro pessoal com status.
  • Tarefas: Lista Kanban com prioridades.
  • Seleção de Veículo: Visualização em tempo real.

2. Dashboard Administrativo

Desktop Only - Acesso via Segredo Administrador

  • KPIs: Total de KM, Viagens, Usuários Ativos.
  • Mapa em Tempo Real: Rastreamento da frota.
  • Feed de Atividade: Eventos em tempo real.
  • Ranking: Gamificação de motoristas.
  • Gerenciamento: Veículos e Tarefas.
  • Relatórios: Exportação CSV.

3. Inteligência Artificial (Gemini)

  • Resumos Semanais em linguagem natural.
  • Etiquetagem automática de Itinerários.
  • Detecção de Anomalias (Planejado).

Tecnologias Utilizadas

Backend Supabase (Postgres, Auth, Realtime)

Estrutura do Projeto

FleetControl/
├── android/             # Projeto Nativo Android
├── src/
│   ├── components/      # UI (Dashboard, Mapas, Forms)
│   ├── services/        # Lógica (Gemini, Rastreamento)

├── supabase/            # SQL & Schema
└── capacitor.config.ts  # Config Mobile

Instalação e Configuração

Variáveis de Ambiente (.env.local)

VITE_SUPABASE_URL=seu_url
VITE_SUPABASE_ANON_KEY=sua_key
VITE_GEMINI_API_KEY=sua_gemini_key

Comandos Úteis

Instalar dependências:

npm install

Rodar Web (Dev):

npm run dev

Rodar Mobile (Android):

npm run build
npx cap sync
npx cap run android
